2.0.0
Rewritten in Rust: one small binary (~1.7 MB) for Windows, macOS and Linux, no Python needed.
Finds every WoW install Battle.net lists, including classic beta; Linux support via Wine/Lutris/Proton/Bottles.
Handles ElvUI's new single ElvUI.toc, does clean installs, retries on network errors and shows errors instead of crashing.
--path, --force, --wait and --no-changelog options.
